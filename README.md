# سامانه جامع GIS و پایش متمرکز (دو بعدی + سه بعدی)

سامانه‌ای تحت وب و سمت‌کاربر (client-side) برای نقشه‌خوانی، مسیریابی، پایش هواشناسی/زلزله/ترافیک،
و تحلیل مکانی — با دو نقشه هم‌گام (Leaflet دو بعدی و Cesium سه بعدی) که به‌طور دقیق از نظر محدوده
و زوم با یکدیگر هماهنگ می‌مانند، هرچند هرکدام می‌توانند نقشه پایه (Base Map) مستقل خود را داشته باشند.

هیچ فرایند ساخت (build) یا نصب پکیجی لازم نیست؛ کل برنامه HTML/CSS/JS ساده است و مستقیماً در مرورگر
اجرا می‌شود.

## اجرا

### روش سریع (محلی)
فایل `index.html` را مستقیماً در مرورگر باز کنید. برخی مرورگرها به دلیل سیاست CORS ماژول‌های
JavaScript را از `file://` اجرا نمی‌کنند؛ در آن صورت یک سرور استاتیک ساده اجرا کنید:

```bash
python3 -m http.server 8080
# سپس مرورگر را به http://localhost:8080 باز کنید
```

### روش GitHub Pages
1. این مخزن را در GitHub push کنید.
2. در تنظیمات مخزن → Pages → Branch را روی `main` (پوشه ریشه) قرار دهید.
3. آدرس منتشرشده (`https://<username>.github.io/<repo>/`) همان برنامه است.

## قابلیت‌ها

- **نقشه دوگانه هم‌گام**: نمایش هم‌زمان نقشه ۲بعدی (Leaflet) و ۳بعدی (Cesium) با تطابق دقیق محدوده
  جغرافیایی و زوم (بر پایه Bounds، نه تقریب). هر پنل نقشه پایه مستقل خود را دارد (۱۵+ نقشه پایه رایگان
  و بدون نیاز به کلید یا ثبت‌نام: OSM، OpenTopoMap، CartoDB، Esri، گوگل و ...).
- **مسیریابی**: جستجوی مکان (Nominatim)، تعیین مبدأ/مقصد، مسیر با OSRM، نمایش هم‌زمان در هر دو پنل.
- **هواشناسی کامل**: کلیک روی هر نقطه از هر پنل → وضعیت جوی لحظه‌ای + پیش‌بینی ۷ روزه + وضعیت دریا و
  امواج (Open-Meteo، رایگان و بدون کلید) در پاپ‌آپ شیشه‌ای. نقشه‌های ویژه جوی (ابر/دما/بارش/باد/فشار)
  با کلید OpenWeatherMap. رادار بارش زنده RainViewer بدون کلید.
- **زلزله**: زمین‌لرزه‌های ۲۴ ساعت اخیر جهان (USGS) با فیلتر بزرگی، نمایش هم‌زمان در هر دو پنل.
- **ترافیک**: ترافیک زنده گوگل (بدون کلید) و جریان/حوادث ترافیکی TomTom (با کلید).
- **تحلیل میدان دید (Viewshed)**: تحلیل واقعی خط دید بر پایه پروفایل ارتفاعی زمین (نمونه‌برداری شعاعی +
  تصحیح انحنای زمین/شکست جوی)، نمایش نقاط قابل‌رؤیت/مسدود روی هر دو نقشه و گنبد برد حسگر در نقشه سه‌بعدی.
- **پروفایل ارتفاعی مسیر**: ترسیم خط روی نقشه و مشاهده نمودار ارتفاعی تعاملی.
- **ابزار رسم و اندازه‌گیری**: خط، چندضلعی، دایره، مستطیل، با محاسبه مساحت/طول.
- **ورود/خروج GeoJSON**: بارگذاری و دانلود ترسیمات.
- **سینک نمادها بین پنل‌ها**: کلیک روی هر نماد (هواشناسی/زلزله/مسیر) در یک پنل، همان رویداد را در پنل
  دیگر هم فعال می‌کند.
- **تنظیمات و کلیدهای API**: ذخیره محلی و امن (localStorage) کلیدهای OpenWeatherMap، TomTom و
  Cesium Ion (اختیاری، برای مدل زمین با کیفیت بالاتر).

## کلیدهای API (اختیاری)

برنامه بدون هیچ کلیدی کاملاً قابل استفاده است (نقشه‌ها، مسیریابی، هواشناسی پایه، زلزله، رادار بارش).
برای قابلیت‌های زیر کلید رایگان لازم است:

| قابلیت | سرویس | لینک دریافت کلید رایگان |
|---|---|---|
| نقشه‌های ویژه هواشناسی (ابر/دما/بارش/باد/فشار) | OpenWeatherMap | https://openweathermap.org/api |
| ترافیک زنده و حوادث ترافیکی | TomTom | https://developer.tomtom.com/ |
| مدل زمین با کیفیت بالاتر (اختیاری) | Cesium Ion | https://ion.cesium.com/ |

کلیدها را در بخش «۸. تنظیمات و کلیدهای API» وارد کنید؛ به‌محض استفاده در هر قابلیتی، به‌صورت خودکار
در مرورگر شما ذخیره می‌شوند (نیازی به زدن دکمه ذخیره نیست، هرچند برای اطمینان توصیه می‌شود).

## ساختار پروژه

```
index.html              رابط کاربری اصلی
css/style.css           استایل‌ها
js/app.js                راه‌اندازی و اتصال ماژول‌ها
js/map.js                هسته نقشه: Leaflet + Cesium، سینک دوربین، اتصال نمادها بین پنل‌ها
js/modules/routing.js    مسیریابی و جستجو
js/modules/traffic.js    ترافیک گوگل و TomTom
js/modules/weather.js    هواشناسی، دریا/امواج، نقشه‌های ویژه جوی
js/modules/disasters.js  زلزله (USGS)
js/modules/analysis.js   تحلیل میدان دید (Viewshed) و پروفایل ارتفاعی
js/modules/settings.js   واکشی و ذخیره کلیدهای API
```

## نکات فنی

- در حالت «همزمان»، دوربین سه‌بعدی برای تطابق دقیق با نقشه دو بعدی روی حالت عمودی (Nadir) قفل می‌شود؛
  چرخش/کج‌کردن آزاد فقط در حالت «فقط سه‌بعدی» در دسترس است.
- اگر پس از مدتی تعامل، انحراف جزئی بین دو نقشه احساس شد، دکمه شناور «هم‌ترازی مجدد» (آیکون چشم) در
  گوشه نقشه، سینک را فوراً دوباره اعمال می‌کند.
- تمام درخواست‌های هواشناسی/ارتفاع/زلزله/مسیریابی مستقیماً از مرورگر کاربر به سرویس‌های عمومی ارسال
  می‌شوند؛ هیچ بک‌اند اختصاصی لازم نیست.
